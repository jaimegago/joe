# Decisions

The normative, append-only decision log lives at
[`docs/DECISIONS.md`](docs/DECISIONS.md). Consult it before re-deciding
anything: it records each architectural choice, its basis, what it supersedes,
and the session that made it (newest entries on top).

This top-level pointer exists so contributors browsing the repo root find the
log on the first try. The log itself stays at `docs/DECISIONS.md` — this file
does not duplicate or replace it.
